# 3D Projection
<b>A side project</b>
<br>
Author : [Novaito](https://github.com/Novaito).
## 2D to 3D
Project 3D points on a 2D screen to visualize 3D objects on 2D.
## Build any form
The principe is simple. Draw anything you want to project on 2D plan.
### Where build a new object
There is a package named <b>forms</b>. Here you just have to create a new class and assemblate points, vertices, and faces like you want.
